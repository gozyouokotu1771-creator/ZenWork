# ZenWork - オールインワン・ワークスペース

**ZenWork** は、作業効率を最大化するために設計された、シンプルで美しいブラウザベースのダッシュボードです。会員登録は一切不要で、ブラウザを開いた瞬間からあなたの生産性をサポートします。



## 特徴
* **完全プライベート**: データはすべてブラウザ（LocalStorage）に保存されるため、サーバーに情報が送信されることはありません。
* **オールインワン**: Todo、スケジュール、カレンダー、習慣化リスト、利益計算機など、必要なツールを1つの画面に集約。
* **ビジネス対応**: 為替レート（USD/JPY）のリアルタイム表示や、物販ビジネスに便利な利益計算・在庫管理機能を搭載。
* **インストール不要**: URLにアクセスするだけで、PCのみすぐに利用可能です。

## 主な機能
1. **ダッシュボード**: 今月の目標設定とリアルタイム為替情報の表示。
2. **Todoリスト**: シンプルなタスク管理。ダブルクリックで編集可能。
3. **スケジュール**: 1日のタイムラインを視覚化。
4. **カレンダー**: 月ごとの予定管理。
5. **習慣化リスト**: 「継続」をサポートするトラッキング機能。
6. **利益計算・在庫管理**: 仕入・売上・手数料・消費税還付を考慮した高度な計算。
7. **メモ機能**: アイデアを即座に書き留める、すりガラスデザインのエディタ。
